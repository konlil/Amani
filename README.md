# LLM3dEngine

A 3D game engine designed for LLM AI as the developer. Built on a trimmed Godot 4.4 core with TypeScript scripting layer.

The current desktop preview experience uses a macOS-focused overlay mode: Godot runs as a separate borderless window, and Tauri aligns it to the preview panel through local IPC and native window positioning.

See [docs/design/](docs/design/) for architecture and design documents.
